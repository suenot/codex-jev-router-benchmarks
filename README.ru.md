# Бенчмарки Codex Jev Router

[English](README.md) · [Полный отчет на английском](BENCHMARK.md) · [Основной проект](https://github.com/suenot/codex-jev-router)

Здесь находятся запускатель бенчмарка, код проверки ответов, задания, трассы, патчи и измерения выбора моделей для субагентов Codex. Установка и рабочий код роутера остаются в [suenot/codex-jev-router](https://github.com/suenot/codex-jev-router). Материалы перенесены из него после версии 0.7.0 без изменения записанных результатов.

## Стоимость полного рабочего процесса

На тех же 12 выбранных задачах по исходникам, по два запуска каждой, **выбор модели перед стартом одиночной сессии Codex** дал расчетную стоимость **$0.184377** с учетом Jev против **$0.452677** у сохраненного прямого Sol high: **на 59,3% меньше**. Строгую проверку прошли **21/24 против 22/24**, суммарное время выросло **на 5,4%**. Это сравнение с ранее сохраненными запусками, без рандомизации порядка; равное качество не установлено. Снижение общей цены дали маршруты на Luna, а группа Sol low оказалась **на 34,7% дороже** прямого Sol high. [Методика и ограничения](BENCHMARK.md#direct-routing-before-the-root-codex-turn).

На 12 заранее заданных задачах по исходникам Django, с двумя повторами каждого варианта, одна сессия Sol high стоила по тарифам API **$0.452677** и прошла **22/24** строгих проверок. Родитель Sol high с одним субагентом, выбранным Jev для каждой задачи, стоил **$0.657100** и прошел **21/24**: **на 45,2% дороже** с учетом Jev. В шести запусках по четыре задачи одна продолжающаяся сессия Sol high стоила **$0.193704** (20/24 проверок), а родитель с четырьмя субагентами — **$0.547248** (22/24), **на 182,5% дороже**. Строгая проверка учитывает формат ответа и точные ссылки на исходники. [Методика и результаты](BENCHMARK.md#full-codex-workflow-one-sol-high-agent-or-a-routed-subagent).

Один парный запуск с исправлением Django дал другой результат: оба варианта прошли локальный официальный тест. Одиночный Sol high стоил **$0.144088**, а родитель Sol high с выбранным Jev субагентом Luna medium — **$0.056660**, **на 60,7% дешевле**, но **на 50,5% медленнее**. По одному запуску нельзя судить об ожидаемой экономии. [Патчи, тесты и ограничения](BENCHMARK.md#full-codex-workflow-one-real-django-code-fix).

## Прежние результаты: только рабочая модель

В прежней выбранной выборке оценивали **только выбранную рабочую модель и решение Jev**: расчетная стоимость API снизилась на 71,0%, с $0.214806 до $0.062317, в девяти парных запусках задач по исходникам Django (9/9 верных ответов в каждом варианте). В трех парных запусках одного ограниченного исправления Django она снизилась на 98,3%, с $0.555916 до $0.009668 (официальный тест прошел 3/3 раза в каждом варианте). **Работа родителя Sol high в эти расчеты не входила**, поэтому они не доказывают экономию полного процесса с субагентом. Для расчета использованы опубликованные тарифы Standard API с коротким контекстом и измеренное число входных, кешированных входных и выходных токенов.

Это **оценка по тарифам API, а не фактические списания за подписку Codex и не прогноз для любой задачи**. Контрольные запуски с той же моделью показали разброс, а ранний синтетический тест не имел чистой базовой конфигурации. Расчет и ограничения приведены в [полном отчете](BENCHMARK.md#earlier-selected-worker-only-cost-savings).

- [BENCHMARK.md](BENCHMARK.md) — результаты, допущения расчета цены и ограничения.
- [benchmarks/](benchmarks/) — входные данные, ответы, трассы, патчи и результаты проверок.
- [scripts/benchmark.mjs](scripts/benchmark.mjs) — запускатель синтетических задач с данными прямо в запросе. Он **не** воспроизводит автоматически эксперименты с правками Django и pytest.
- [grade.py](benchmarks/django-source-tasks-2026-09-24/grade.py) — проверка 18 ответов по исходникам; параметр `--source` дополнительно сверяет факты с закрепленным коммитом Django.
- [scripts/agent-overhead.mjs](scripts/agent-overhead.mjs) — сравнение 12 задач на закрепленном коммите Django: один sol high без субагентов против родителя sol high с субагентом, модель которого выбрал Jev. Складывает расход родителя и субагента, проверяет ответы и ссылки на исходники, сохраняет трассы и оценку стоимости.
- [scripts/batch-agent-overhead.mjs](scripts/batch-agent-overhead.mjs) — сравнение одной сессии sol high на четырех задачах с родителем sol high и четырьмя отдельно маршрутизированными субагентами. Три заранее заданные группы охватывают все 12 задач.
- [scripts/code-fix-agent-overhead.mjs](scripts/code-fix-agent-overhead.mjs) — сравнение полного процесса на исправлении Django 16527 с возможностью повторить локальный официальный тест по сохраненным патчам.
- [scripts/direct-routed-root.mjs](scripts/direct-routed-root.mjs) — выбор модели до запуска одной корневой сессии; [проверка результатов](scripts/audit-direct-root.py) заново сверяет ответы, расход, маршруты и расчет стоимости.
- [benchmarks/django-task-suite-2026-09-26/](benchmarks/django-task-suite-2026-09-26/) — заранее зафиксированные задания, ожидаемые факты, проверка, результаты и трассы.

Клонируй оба репозитория рядом и установи закрепленную зависимость основного проекта:

```sh
gh repo clone suenot/codex-jev-router
gh repo clone suenot/codex-jev-router-benchmarks
cd codex-jev-router
npm ci
cd ../codex-jev-router-benchmarks
npm run check
```

Если каталоги расположены иначе, задай `CODEX_ROUTER_REPO=/absolute/path/to/codex-jev-router`. Запускатель импортирует рабочие файлы роутера из этого каталога. Для нового запуска синтетического теста нужны авторизация Codex CLI и настроенный движок решений:

```sh
npm run benchmark -- --repetitions 3 --output /tmp/codex-router-benchmark.json
```

Перед сравнением расчетных цен прочитай [отчет](BENCHMARK.md): ранний синтетический запуск сделан до исправления изоляции, а результаты на настоящих репозиториях относятся к небольшой выбранной выборке.

Чтобы повторить сравнение одного агента с родителем и субагентом, возьми коммит Django из [описания набора задач](benchmarks/django-task-suite-2026-09-26/manifest.json):

```sh
python3 benchmarks/django-task-suite-2026-09-26/grade.py --source /path/to/pinned/django
npm run benchmark:agents -- --repo /path/to/pinned/django --output /tmp/agent-overhead-results.json --repetitions 2
npm run benchmark:batch -- --repo /path/to/pinned/django --output /tmp/batch-overhead-results.json --repetitions 2
npm run benchmark:direct-root -- --repo /path/to/pinned/django --output /tmp/direct-root-results.json --repetitions 2
```

Контрольная сессия принудительно запускается без субагентов. Во втором варианте родитель запускает одного субагента с моделью, которую выбрал настроенный движок решений. У каждого запуска отдельный профиль Codex. Порядок вариантов чередуется, а проверка ответа сверяет значения и строки исходников. Методика и ограничения описаны в [отчете](BENCHMARK.md).
